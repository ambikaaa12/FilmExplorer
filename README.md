
# File Explorer

A simple and user-friendly **File Explorer** application for browsing, managing, and organizing files and folders on a computer.

## Features

* Browse files and folders
* Open folders and navigate through directories
* View file names and extensions
* Create new folders
* Rename files and folders
* Delete files and folders
* Search for files
* View basic file information
* Simple and easy-to-use interface

## Technologies Used

* HTML
* CSS
* JavaScript

## Project Structure

```text
File-Explorer/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/File-Explorer.git
```

2. Open the project folder.

3. Open `index.html` in your web browser.

## Usage

Use the file explorer interface to navigate through folders, view files, and perform basic file management operations.
